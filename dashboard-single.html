How the number is made

Implied value = TVL × peer multiple × growth factor × patience factor.

  • Peer multiple: the median market-cap-to-TVL multiple of the tokens already trading in the protocol’s own category. A category with fewer than 3 live peers falls back to the whole-market median. Clamped to 0.02–2.00.
  • Growth factor: from the 7-day TVL change, clamped to −40%…+80%, worth 0.84× to 1.32×. No reported change counts as flat.
  • Patience factor: from how long the protocol has been tracked with no token recorded — 0.75 for a new listing, rising to 1.00 after three years. Unknown listing date counts 0.85.
  • Confidence follows the peer sample: high with 8+ peers and a known listing date, medium with 3+, otherwise low.

The snapshot says a protocol records no token — never that it has none. A protocol on the list may still hold a token its DefiLlama record does not carry. Implied value is this board’s own claim, not a forecast and not financial advice: it does not predict whether or when any token is issued. Farm steps are a starting plan, not a guarantee of any reward.
